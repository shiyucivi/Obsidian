### 1 监听关闭信号
`tokio::signal`可以监听多种操作系统中的各种关闭信号。其中本地进程可以监听`Ctrl+C`，unix系统中可以监听`SIGRERM`，其他系统中使用`std::future::pending`占位。使用时需要使用`#cfg[]`宏开启条件编译。
由于需要同时监听到多种类型的关闭信号，需要使用`select!`宏来进行协同：
```rust
use tokio::signal;

#[tokio::main]
async fn main () {
    println!("服务运行中...");
    // 等待关闭信号
    shutdown_signal().await;
    // 执行清理工作（如关闭数据库连接、保存状态等）
    println!("正在执行清理任务...");
}

async fn shutdown_signal() {
	let ctrl_c = async {
		signal::ctrl_c()
			.await
			.expect("failed to install Ctrl+C handler");
	};
	#[cfg(unix)]
	let terminate = async {
		signal::unix::signal(signal::unix::SignalKind::terminate())
			.expect("failed to install signal handler")
			.recv().await;
	};
	#[cfg(not(unix))]
	let terminate = std::future::pending::<()>();
	tokio::select! {
		() = ctrl_c => {},
		() = terminate => {}
	};
	println!("收到停机信号 (SIGINT 或 SIGTERM)");
}
```
### 2 在Axum服务中监听
如果要在多个异步线程中执行清理工作需要每个线程中都监听关闭信号（主线程广播）。axum提供了方便的`serve::with_graceful_shutdown`方法，传入一个处理关闭信号的函数：
```rust
axum::serve(listener, app)
	.with_graceful_shutdown(shutdown_signal())
	.await;
	
async fn shutdown_signal() {
	let ctrl_c = async {
		signal::ctrl_c()
			.await
			.expect("failed to install Ctrl+C handler");
	};
	#[cfg(unix)]
	let terminate = async {
		signal::unix::signal(signal::unix::SignalKind::terminate())
			.expect("failed to install signal handler")
			.recv().await;
	};
	#[cfg(not(unix))]
	let terminate = std::future::pending::<()>();
	tokio::select! {
		() = ctrl_c => {},
		() = terminate => {}
	};
}
```
