在这个例子中，我们要实现一个`AppError`类型的错误，这个错误类型包含两个枚举：提取错误和内部处理错误。在接口handler中进行返回并在中间件中进行处理和打印。
### 1 自定义错误类型
如果想将一个错误类型（通常是枚举）作为接口请求的返回值类型，至少需要满足两个trait：`Debug`（或`Display`）和`response::IntoResponse`。同时最好实现`Form<T>`，其中T可以是其他crate中的错误类型。
```rust
use axum::{
    extract::{
        rejection::{self, JsonRejection}
    },
}
// 一个第三方错误类型
use time_library;
// 一个自定义错误类型
#[derive(Debug)]
enum AppError {
    // Json解析失败
    JsonRejection(JsonRejection),
    // 一个其他crate中的错误类型
    TimeError(time_library::Error),
}
// 将JsonRejection转为AppError
impl From<JsonRejection> for AppError {
	fn from(rejection) -> Self {
		Self::JsonRejection(rejection)
	}
}
// 将一个第三方错误类型转为AppError
impl From<time_library::Error> for AppError {
    fn from(error: time_library::Error) -> Self {
        Self::TimeError(error)
    }
}
```
#### 1.1 实现`IntoResponse`与扩展类型
虽然Http请求是无状态的。但是我们可以为`Response`类型设置扩展类型（`Extension`）数据。这扩展类型仅限于服务器内部处理，不会发送给客户端。
`Extension`是一个TypedMap（类型映射），`insert`方法插入时只需要传入一个类型（需要实现`Clone`、`Send`、`Sync`），`get`方法获取时只需要通过泛型传入类型参数即可获取对应类型的数据。
```rust
use axum::{
	response::{IntoResponse, Response},
	http::StatusCode,
}
//在IntoResponse中添加Extension
impl IntoResponse for AppError {
	fn into_response(self) -> Response {
        // 用于自定义错误响应的响应体的类型
        #[derive(Serialize)]
        struct ErrorResponse {
            message: String,
        }
        // 根据错误类型转换不同的响应体
        // status和message用于返回给客户端，err用于内部处理
        let (status, message, err) = match &self {
	        // 
	        AppError::Rejection(rejection) => {
		        // 来自请求的错误，不需要额外处理
		        (rejection.status(), rejection.body_text(), None)
	        }
	        AppError::TimeError(_err) => {
		        // 服务器内部错误，需要处理并在日志中打印
		        (
			        StatusCode::INTERNAM_SERVER_ERROR,
			        "Something went wrong".to_string(),
			        Some(self)
		        )
	        } 
        }
        let mut response = 
		    (status, AppJson(ErrorResponse { message })).into_response();
		// 如果err不是None，将err插入到Extension中
		// 这里使用Arc包裹自动实现Clone、Send和Sync
		if let Some(err) = err {
			response.extensions_mut().insert(Arc::new(err));
		}
		response
    }
}
```
在中间件函数中获取扩展类型中的错误并进行记录
```rust
async fn log_app_errors(request: Request,next: Next) -> Response {
	let response = next(request).await;
	if let Some(err) = response.extension().get<Arc<AppError>> {
		tracing::error!(?err)
	}
	response
}
```
#### 1.2 自定义提取器并为提取器设置错误类型
这里使用派生宏来快速包装一个Json提取器，当提取错误时将错误转换为`AppError`。
```rust
use axum::{
    extract::{FromRequest}
}
#[derive(FromRequest)]
#[from_request(via(axum::Json), rejection(AppError))]
struct AppJson<T>(T);
// 同时为AppJson实现IntoResponse
impl <T> IntoResponse for AppJson<T>
where axum::Json<T>: IntoResponse
{
	fn into_response(self) -> Response {
		axum::Json(self.0).into_response()
	}
}
```
在handler中使用这个提取器:
```rust
// state
#[derive(Default, Clone)]
struct AppState {
    next_id: Arc<AtomicU64>,
    user_map: Arc<Mutex<HashMap<u64, User>>>,
}
// 作为响应体的类型
#[derive(Serialize, Clone)]
struct User {
    id: u64,
    name: String,
    created_time: Timestamp,
}
// 作为请求体的类型
#[derive(Deserialize)]
struct UserParams {
    name: String,
}
async fn create_user_handler(
	state: State<AppState>,
	AppJson()
) -> Result<AppJson<User>, AppError> {
	let id = state.next_id.fetch_add(1, Ordering::SeqCst);
    let created_time = Timestamp::now()?;

    let user = User {
        id,
        name:params.name,
        created_time
    };
    let mut user_map = state.user_map.lock().unwrap();
    user_map.insert(id, user.clone());
    Ok(AppJson(user))
}
```
### 2 使用`thiserror`快速转换错误类型
可以使用`thiserror`提供的派生宏来快速实现`axum`中或其他crate的错误类型到自定义错误类型的转换：
```rust
use axum::{
    extract::{rejection::JsonRejection},
    response::{IntoResponse},
};
use validator;
use thiserror::Error;

#[derive(Debug, Error)]
pub enum AppError {
    #[error(transparent)]
    ValidationError(#[from] validator::ValidationErrors),
    #[error(transparent)]
    AxumFormRejection(#[from] JsonRejection),
}
impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        match self {
            Self::ValidationError(_) => {
                let message = format!("Input validation error: [{self}]").replace('\n', ", ");
                (StatusCode::BAD_REQUEST, message).into_response()
            }
            Self::AxumFormRejection(_) => {
                let message = self.to_string();
                (StatusCode::BAD_REQUEST, message).into_response()
            }
        }
    }
}
```
