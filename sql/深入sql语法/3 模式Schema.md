pgsql的数据库层级结构为数据库集簇 - 数据库 - 模式 - 数据库表 - 行列。
一个数据库集簇中通常包含一个或多个数据库，但是可以共享一个数据库连接，在连接中指定要连接的数据库。
一个数据库中可以包括多个命名模式。模式中还包括其他命名对象，例如表、数据类型、函数和自定义操作符。相同的对象名称可以被用于不同的模式中而不会出现冲突。可以为每个用户分配其在数据库中的模式。
#### 1 创建模式`CREATE SCHEMA`
```sql
CREATE SCHEMA myschema;
```
需要访问某个模式下的某个表，可以使用`myshcema.table_name`。
```sql
-- 级联删除模式
DROP SCHEMA myschema ESCADE;
```
#### 2 公共模式
默认情况下所有创建的表及对象都会被放入`Public`模式中。
#### 3 模式权限
默认情况下，用户无法访问他们不拥有的模式。要允许访问，模式的所有者必须授予该模式上的`USAGE`权限。 
默认情况下，每个人在模式`public`上都有该权限。
