#### 1 表基础
创建表：
```sql
CREATE TABLE products (
    product_no integer,
    name text,
    price numeric
);
```
##### 1.1 列默认值
一个列可以分配一个默认值，创建行时如果不赋值则使用默认值：
```sql
CREATE TABLE products (
    product_no integer DEFAULT SERIAL,
    name text,
    price numeric DEFAULT 9.99,
    create_time CURRENT_TIMESTAMP
);
```
`serial`是一个动态表达式，是`nextval(products_product_no_sql)`的速写。表示自动递增。
##### 1.2  生成列
生成列是从其他列自动计算而来的列。生成列包括两种：
- 存储列，在创建行计算，像普通列一样存储
- 虚拟列，在读取时才计算，类似于视图，不存储
```sql
CREATE TABLE people (
    height_cm numeric,
    height_in numeric GENERATED ALWAYS AS (height_cm / 2.54) STORED
);
```
`GENERATED`表示该列为生成列，`STORED`表示存储列。
生成列默认不能用`INSERT`或`UPDATE`写入。在继承时生成列也必须保持不变。
#### 2 列约束
SQL允许在表上定义列数据的约束，如果插入或更新时违反约束则抛出错误。
约束包括列级约束和表级约束。区别是表级约束在创建表的语句的最后一行并且需要声明所约束的列。
##### 2.1 检查约束`CHECK`
`CHECK`检查约束是最常见的约束类型
```sql
CREATE TABLE products (
    product_no integer,
    name text,
    price numeric CHECK (price > 0)
);
```
一个检查约束可以同时约束多个列，例如约束折扣价格不能高约标准价格：
```sql
CREATE TABLE products (
	price numeric CHECK(price > 0),
	discounted_price numeric CHECK (discounted_price > 0),
    CHECK (price > discounted_price)
);
```
这种约束需要作为独立项出现在表的列中而不依附于某一列。
##### 2.2 非空约束`NOT NULL`
`NOT NULL`非空约束要求列的值不能为`NULL`。
```sql
CREATE TABLE products (
	product_no integer NOT NULL,
    name text NOT NULL,
    price numeric CHECK (price > 0)
);
```
##### 2.3 唯一约束`UNIQUE`
`UNIQUE`唯一约束要求列中的数据在表中是唯一的：
```sql
create TABLE products (
	product_no integer NOT NULL UNIQUE,
    name text NOT NULL,
    price numeric CHECK (price > 0)
);
-- 可以同时约束多个列
create TABLE products (
	product_no integer NOT NULL,
    name text NOT NULL,
    price numeric CHECK (price > 0),
    UNIQUE(product_no, name)
);
```
通常情况下，`NULL`之间是不会被视为相等的。如果想修改这一行为，可以使用`NULLS NOT DISTINCT`：
```sql
create TABLE products (
	product_no integer UNIQUE NULlS NOT DISTINCT,
    name text NOT NULL,
    price numeric CHECK (price > 0)
);
```
##### 2.4 主键约束`PRIMARY KEY`
```
一个主键约束表示可以用作表中行的唯一标识符的一个列。主键必须非空且唯一。
```sql
CREATE TABLE products (
    product_no integer PRIMARY KEY,
    name text,
    price numeric
);
-- 主键也可以跨越多个列
CREATE TABLE products (
    product_no integer,
    name text,
    price numeric,
    PRIMARY KEY (product_no, name)
);
```
==**一个表中最多只有有一个主键。**==
##### 2.5 外键`FOREIGN KEY`
外键约束指定一列的数据必须与另一个表中的某一列匹配，即两个关联表之间的引用完整性：
```sql
CREATE TABLE products (
    product_no integer PRIMARY KEY,
    name text,
    price numeric
);
-- 指定order_product_no为来自products的外键
CREATE TABLE orders (
	order_id integer PRIMARY KEY,
	product_no integer REFERENCES products (product_no),
	-- 列名相同的时候可以省略列名
	qutantity integer
);
-- 也可以同时约束多个列为外键约束
CREATE TABLE orders (
	order_id integer PRIMARY KEY,
	product_no integer,
	product_name text,
	qutantity integer,
	FOREIGN KEY (product_no, product_name) REFERENCES products (product_no, product_name)
);
```
一个表可以有多个外键，用于实现多个表之间的关联关系。
##### 2.6 外键的限制删除与级联删除
限制删除和级联删除是关联表之间限制进行删除操作的两个相反的约束。
`ON DELETE DISTRAIN`限制删除：子表中存在引用父表的行，则禁止删除父表中的该行，抛出异常
```sql
CREATE TABLE users {
	id INTEGER SERIAL PRIMARY KEY,
	name TEXT
};
CREATE TABLE orders {
	id SERIAL PRIMARY KEY,
	user_id INTEGER REFERENCES users(id) ON DELETE DISTRAIN
};
```
`ON DELETE CASCADE`级联删除：父表中删除一行，子表自动删除所有引用该行的行
```sql
CREATE TABLE users {
	id INTEGER SERIAL PRIMARY KEY,
	name TEXT
};
CREATE TABLE orders {
	id SERIAL PRIMARY KEY,
	user_id INTEGER REFERENCES users(id) ON DELETE CASCADE
};
```
##### 2.7 定义约束
可以使用`CONSTRAINT`子句为约束命名。基本语法：
`CONSTRAINT constraint_name constraint_type`。
```sql
CREATE TABLE orders {
	id SERIVAL,
	user_id INT,
	-- 定义主键约束
	CONSTRAINT pk_orders PRIMARY KEY (id),
	-- 定义外键约束
	CONSTRAINT fk_orders FOREIGN KEY (user_id) REFERENCES users(id),
};
```
这种定义约束方便用于修改删除约束。
#### 3 修改表的列定义
修改表中已存在的结构（列、约束、默认值等）的基础语法是
```sql
ALTER TABLE tablename [OPERATION]
```
###### 增加列`ADD COLUMN`
```sql
ALTER TABLE products ADD COLUMN description text;
```
增加列的同时可以像创建表一样定义列的约束。
###### 移除列`DROP COLUMN`
```sql
ALTER TABLE products DROP COLUMN description;
```
如果列涉及到外键，
###### 增加约束`ADD`
```sql
ALTER TABLE products ADD CHECK (price > 0);
ALTER TABLE orders 
ADD CONSTRAINT fk_orders FOREIGN KEY (user_id) REFERENCES users(id)
```
###### 移除约束`DROP`
```sql
ALTER TABLE orders DROP CONSTRAINT fk_orders;
```
###### 修改列默认值`ALTER COLUMN SET DEFAULT`
```sql
ALTER TABLE products ALTER COLUMN price SET DEFAULT 9.9;
```
###### 修改列的数据类型`ALTER COLUMN TYPE`
```sql
ALTER TABLE products ALTER COLUMN price TYPE numeric(0.2);
```
###### 重命名列`RENAME TO`
```sql
ALTER TABLE products RENAME COLUMN product_no TO product_id;
```
