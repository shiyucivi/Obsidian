#### 1 列引用
`tablename.columnname`
#### 2 位置参数
位置参数就是sql语句中的参数占位符，常用于创建一个函数，通过传入外部的参数来动态执行。一般使用`$1`、`$2`、...`$n`来表示。
```sql
-- 预编译语句
PREPARE get_user(int) AS
SELECT * FROM users WHERE id = $1;
-- 执行时传入参数
SELECT get_user(123);
```
#### 3 下标
如果一个表达式是数组类型的值。那么可以从该数组中提取一个特定元素或一个连续的切片：
```sql
table.arraycolumn[4]
```

```sql

:: --类型转换
[] --数组截取
+-  -- 加减
^ --指数
* / % --乘、除、取模
BETWEEN  --范围包含
IN --集合成员关系
LIKE ILIKE SIMILAR -- 字符串匹配
> < = >= <= --大小比较
IS ISNULL NOTNULL -- IS TRUE, IS FALSE, IS NULL等
NOT -- 逻辑非
AND -- 逻辑并
OR --逻辑或
```
#### 5 函数调用
自定义函数的语法为：
```sql
-- OR REPLACE表示覆盖默认函数
CREATE OR REPLACE FUNCTION function_name(parameter_name parameter_type)
RETURNS return_type
AS $$
-- 函数体逻辑
$$ LANGUAGE SQL;
```
例如：
```sql
CREATE OR REPLATE FUNCTION get_user_state(user_id INT)
RETURNS TEXT
AS $$
	DECLARE use_age INT;
	BEGIN
		SELECT age INTO user_age FROM users WHERE id = user_id;
		IF user_age IS NULL THEN
			RETURN 'User not found';
		ELSEIF user-age < 18 THEN
			RETURN 'Minor';
		ELSE
			RETURN 'Audlt';	
		END IF;
	END	
$$ LANGUAGE SQL;
-- 调用
get_uer_state(28755);
```

#### 8 类型转换
类型转换用于将一个值显式的转为为另一个类型的数据：
```sql
SELECT CAST('123' AS INTEGER); ---123, sql标准类型转换语法
SELECT '123'::INTEGER; --pgsql提供的简写语法
```
某些表达式中会存在隐式类型转换：
```sql
SELECT '42' = 42; --true
```
#### 9 排序规则表达式
基本语法：`expression COLLATE collation_name`
常用于：`ORDER BY` 、`WHERE` 、`GROUP BY` 、建表时的列定义排序。
默认情况下，如果不使用`COLLATE`声明排序规则，pgsql使用数据库创建时的`LC_COLLATE`进行排序。
```sql
-- 使用"C"排序，按字节值排序(ASCII顺序，速度最快)
SELECT a, b, c FROM tbl ORDER BY a COLLATE "C";
```
#### 10 标量子查询
标量子查询是一种圆括号内的普通`SELECT`查询，它刚好返回一行一列。适用于为每一行动态查询某一个值的场景。
```sql
-- 查询每个state最大的城市人口
SELECT name, (SELECT max(pop) from cities WHERE cities.state = states.name) FROM states;
-- 相当于
SELECT states.name, max(cities.pop) FROM state left JOIN cities 
ON cities.state = states.name
GROUP BY states.name; 
```
这种查询逻辑类似于`JOIN`+`GROUP BY`，但写法更直观。但是在行较多时性能不如`JOIN`+`GROUP BY`.。
