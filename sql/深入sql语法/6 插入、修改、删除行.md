### 1 插入行`INSERT INTO`
插入时必须提供完整的行
```sql
-- 创建并插入数据
CREATE TABLE products (
	id integer,
	name text,
	price numeric
);
INSERT INTO products VALUES (1, "Milk", 1.99);

```
如果没有所有列的值，那么需要列出已知的列，数据库会按默认值填充未知的列：
```sql
INSERT INTO products (name, price, id) VALUES ('Cheese', 9.99, 1);
```
直接插入查询的结果：
```sql
INSERT INTO products (id, name, price)
  SELECT product_no, name, price FROM new_products
    WHERE release_date = '2026-04-16';
-- INSERT INTO列出的值必须和SELECT列出的值一一对应
```
### 2 更新行`UPDATE SET`
```sql
UPDATE products SET price = 10, name = 'Coca' where id = 1;
-- 或者如果想批量更新，用于新值的表达式也可以引用行中现有的值
UPDATE products SET price = price * 1.5;
```
### 3 删除行`DELETE FROM`
```sql
DELETE FROM products WHERE id = 1;
```
