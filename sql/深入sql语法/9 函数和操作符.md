### 1 布尔操作符
布尔操作符包括`AND`，`OR`，`NOT`分别代表与、或、非。
PgSQL不会对非布尔值进行隐式转换，而是直接报错。
### 2 比较表达式
#### 2.1 比较操作符
所有的比较操作符的返回值都是布尔值。
比较操作符包括`=`, `<>`（等同于`!=`）, `<`, `<=`, `>`, `>=`。
比较操作只适用于具有自然排序的内置数据类型，例如数字、字符串和日期/事件类型。如果操作符两端类型兼容会进行隐式转换，否则会报错。
#### 2.2 比较谓词
比较谓词的行为和比较操作符很类似，但是语法有所不同。
- `BETWEEN`用于检查值是否在某个范围之间，通常与`AND`搭配使用
```sql
SELECT * FROM orders WHERE price BWTWEEN 10 AND 50;
-- 范围包含上下界，等效于
SELECT * FROM orders WHERE price >= 10 AND price <= 50;
```
- `IN`用于检查值是否位于列表中
```sql
SELECT * FROM users WHERE status IN ('active', 'pending');
```
- `IS`用于检查值是否为`NULL`以及判断是否相等（`=`比较符不能判断`NULL`）
```sql
a IS NULL; -- 判断a是否为NULL
a IS NOT DISTINCT FROM b  -- 如果a=b返回true（包括NULL）
a IS NOT DISTINCT FROM b -- 如果a≠b返回true（包括NULL）
```

### 5 模式匹配
#### 5.1 `LIKE`
`LIKE`用于将字符串匹配指定的模式，返回布尔值：`string LIKE parttern`。区分大小写。
匹配时，模式中的`%`代表的任意数量字符（`%`只能出现在开头结尾），`_`表示固定数量的字符（几个`_`代表几个数量的字符，可以出现在任意位置）
```sql
'abc' LIKE 'abc'; --true
'abc' LIKE 'a%'; --true,匹配以'a'开头的字符串
'abc' LIKE '%c'; --true,匹配以'c'结尾的字符串
'abc' LIKE '%b%'; --true,匹配包含'b'的字符串

'abc' LIKE '_b_'; --true
'abc' LIKE 'a_c'; --true
'user' LIKE 'user_'; --false
```
如果需不需要区分大小写，可以使用`ILIKE`
