表继承可以方便地从一个表创建一个新的具有相同数据列的表。
```sql
CREATE TABLE cities (
	name text,
	polulation float,
	location point,
);
CREATE TABLE capitals (
	state char(2)
) INHERITS (cities);
```
默认情况下，从父表查询将也会对所有子表进行查询，例如：
```sql
SELECT name, polulation FROM cities WHERE popluation > 10000;
-- 会查询出cities表和capitals表中满足条件的行
```
如果想查询或修改子表，可以在表名前加上`ONLY`关键字：
```sql
SELECT name, polulation FROM ONLY cities WHERE popluation > 10000;
```
**==`INSERT`父表不会影响子表，但`UPDATE`和`DELETE`会影响子表，使用时务必加上`ONLY`。==**
### 1 约束继承
PgSql的继承设计遵循一个原则：
**子表的数据是父表数据的一部分**
继承时，子表不会继承父表的外键约束、主键或唯一约束。其余约束如`CHECK`、`NOT NULL`、类型、默认值等会继承。同时父表的数据也不会被带入子表中。
如果不想继承检查约束和非空约束，可以使用`NO INHERIT`结尾。
**==外键约束不会继承，但是向子表中`INSERT\UPDATE`时仍然受到约束。==**
**==父表的主键不会继承，子表中的可以存在该列重复的数据，父表与子表之间也不会检查该列==**
### 2 多表继承
一个表可以继承多个表，只要这些表的列不冲突。
```sql
CREATE TABLE person (
    id SERIAL,
    name TEXT
);
CREATE TABLE employee (
    salary NUMERIC,
    department TEXT
);
CREATE TABLE manager (
    level INT
) INHERITS (person, employee);
```
继承时无法直接指定主键、外键等约束，因此需要创建表后再用`ALTER`修改表的约束：
```sql
ALTER TABLE manager ADD CONSTRAINT pk PRIMARY KEY (id);
```
