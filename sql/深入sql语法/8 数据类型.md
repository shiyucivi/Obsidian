### 1 数值类型
数值类型由2、4和8字节的整数、4和8字节的浮点数以及可选精度的小数构成。
- **整数类型**包型`smallint`、`integer`和`bigint`，分别代表2、4、8字节整数。
- **浮点数类型**包括`real`和`double precision`，分别代表单精度和双精度浮点数，它们是不精确的。
- 类型`numeric`可以存储非常多位且任意精度的数字。并且是计算精确的。特别适用于货币金额和其他要求计算准确的数量。
`numeric`的最大精度（总共数字位数）和最大标度（小数点后位数）可以配置：`NUMERIC(10 ,2)`表示最多可以存储 10 位数字，其中小数点后占 2 位。
### 2 字符类型
字符类型包括三种：
- `varchar(n)`：有限长度的字符串
- `char(n)`：定长字符串，空格填充
- `text`：不限长度的字符串
### 3 日期/时间
- `timestamp` 无时区时间
- `timestamp with time zone` 有时区时间，简写为`temestamptz`
- `date` 日期，无时间
- `time` 一天中的时分秒，无时区
- `time with time zone` 一天中的时分秒带时区
推荐时间存储使用`timestamptz`或`date`：
```sql
CREATE TABLE orders {
	date date,
	create_time timestamptz
}
```
#### 3.1 时间输入输出
`TIMESPAMPTZ`推荐输入使用ISO 8601格式：如 `'2026-04-22T17:54:30+08'` 或 `'2026-04-22 17:54:30+08'`。
```sql
INSERT INTO orders (create_time) 
VALUES ('2026-04-22 17:54:30+08'::timestamptz);
```
输出时间推荐使用函数`to_char()`来进行格式化：
```sql
SELECT TO_CHAR(create_time, 'YYYY-MM-DD HH24:MI:SS') as create_time FROM orders;
```
### 4 布尔类型
布尔类型只有`boolean`一个类型。
真状态的值包括：`true` `yes` `on` `1`
假状态的值包括：`false` `no` `off` `0`
### 5 枚举
枚举（枚举）类型是 由一组静态、有序的值组成。
创建枚举值字段：
```sql
CREATE TYPE weekday AS ENUM ('Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat');
CREATE TABLE orders (
	id int,
	weekday weekday,
);
INSERT INTO orders VALUES (21, 'Sun');
```
创建枚举类型时枚举值的顺序即为枚举值的排序（从小到大）
```sql
SELECT * FROM orders WHERE weekday > 'Tue' ORDER BY weekday;
```
### 6 几何类型
几何数据类型表示二维空间对象。包括点`point`，线`line`，`lesg`线段，`box`矩形框，`path`折线路径、`polygon`多边形，`circle`圆形。
通常不使用Pg原生几何类型，而是PostGIS中的扩展类型
### 7 UUID
uuid是全局唯一通用标识符，同一算法几乎不可能生成相同的数字。一个 UUID 被写成一个小写十六进制位的序列，例如`a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11`。
可以使用`gen_random_uuid()`来生成一个随机的Uuid：
```sql
INSERT INTO users (id, create_time) VALUES (
	gen_random_uuid(),
	'2026-04-22 17:54:30+08'::timestamptz
);
```

### 9 数组类型
PostgreSQL 允许一个表中的列定义为变长多维数组。可以创建基类型、枚举类型、组合类型、范围类型或域的数组。
```sql
CREATE TABLE sal_emp (
    name            text,
    pay_by_quarter  integer[],
    schedule        text[][]
);
INSERT INTO sal_emp VALUES (
	'Bill',
    '{10000, 10000, 10000, 10000}',
    '{{"meeting", "lunch"}, {"training", "presentation"}}'
);
```
可以指定数据的长度为固定值：
```sql
CREATE TABLE tictactoe (
    squares   integer[3][3]
);
```
### 9 组合类型
组合类型是字段名和数据类型的组合列表：
```sql
CREATE TYPE inventory_item AS (
    name            text,
    supplier_id     integer,
    price           numeric
);
CREATE TABLE on_hand (
    item      inventory_item,
    count     integer
);
INSERT INTO on_hand VALUES (ROW('fuzzy dice', 42, 1.99), 1000);
```
组合类型中的类型不能包含约束
